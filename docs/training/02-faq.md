# Perguntas Frequentes (FAQ)

## Geral

### O que é o Serv Conquista?
O Serv Conquista é o Portal do Servidor Inteligente, uma plataforma que centraliza informações e serviços para servidores públicos municipais. Inclui um assistente virtual com inteligência artificial que responde dúvidas com base na documentação oficial.

### Quem pode usar o Serv Conquista?
Todos os servidores públicos municipais: efetivos, comissionados e temporários.

### O assistente virtual substitui o RH?
Não. O assistente é uma ferramenta complementar que facilita o acesso à informação. Para procedimentos que exigem documentação física ou assinaturas, o servidor ainda precisa comparecer ao RH.
